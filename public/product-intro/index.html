五级结构化关联

一条病历，拆成五层可查询的数据。

自由文本的病程记录没法统计。系统把每位患者的诊疗过程拆成五个层级，逐层挂载、逐级可查：上一层是下一层的「文件夹」，任何一条化验、任何一次给药，都能追溯到它属于哪次就诊、哪个治疗段、哪条治疗线。

治疗线

LINE

按「第几线治疗」组织：一线、二线、三线……记录该线的情境、方案与起止，是病程的顶层骨架。

例 · 一线：挽救性放疗 + ADT；二线：阿比特龙；三线：多西他赛化疗。
2

治疗段

EPISODE

一条线里具体执行的治疗阶段：某次放疗、某段内分泌、某周期化疗，含起止日期、疗效与停药原因。

例 · 一线下的「戈舍瑞林 ADT 段」2023-06 → 至今，疗效评估 PR。
3

就诊

VISIT

治疗段内的一次门诊 / 住院：记录日期、症状、体能，是当次所有检查与处理的容器。

例 · 2026-11-12 门诊复查，ECOG 1，无骨痛。
4

随访行

RECORD

就诊里逐条的随访记录：PSA、睾酮、疗效、毒性，一行一个时间点，构成连续曲线。

例 · 该行 PSA 1.9 ng/mL、睾酮 16 ng/dl，疗效 SD。
5

检查 / 不良事件

ITEM · CTCAE 5.0

随访行挂载的具体项目：化验、影像、病理，以及按 CTCAE 5.0 分级的不良事件。

例 · 血常规 WBC 3.2；不良事件「乏力 G2」。
串起来看：一位患者的「二线治疗」里有一段「阿比特龙治疗段」，段内 2026-11-12 的「就诊」记了一条「随访行」，行上挂着「PSA 1.9」与「乏力 G2」。层层挂载，所以统计「二线阿比特龙的 PSA 变化」或「某药 G2 以上毒性发生率」时，直接按层级筛选即可，不用翻自由文本。
二线治疗→阿比特龙段→11-12 就诊→随访行→PSA 1.9 / 乏力 G2

手术、化疗周期、给药与不良事件自动镜像为时间轴节点，删除时同步清理，不留孤儿记录。
